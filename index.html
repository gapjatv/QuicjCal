소개 / About

QuickCal은 Ctrl+Alt+C 를 누르면 작은 팝업이 뜨고, 날짜·시간·알림 시각과 일정 내용을 입력한 뒤 Enter 를 누르면 내 구글 캘린더에 일정과 팝업 알림이 바로 등록되는 개인용 도구입니다.

QuickCal is a personal desktop tool. Press Ctrl+Alt+C, pick a date, type the event, press Enter, and the event (with a popup reminder) is created in your own Google Calendar.

주요 기능 / Features

  • 전역 단축키로 팝업 호출 / Global hotkey popup
  • 오늘 또는 원하는 날짜 선택, 시·분, 몇 분 전 알림 설정 / Date, time and reminder selection
  • Enter 또는 등록 버튼으로 구글 캘린더에 즉시 등록 / One-key creation in Google Calendar
  • 여러 구글 계정을 추가하고 선택해서 등록 / Multiple Google accounts
  • 모든 데이터는 사용자의 PC와 사용자의 구글 계정에만 존재 / Data stays on your PC and in your Google account

구글 데이터 사용 / Google User Data

QuickCal은 사용자가 입력한 일정을 사용자의 구글 캘린더에 생성하기 위해 Google Calendar API 권한만 요청합니다. 자세한 내용은 개인정보처리방침을 확인하세요.
QuickCal requests only the Google Calendar permission needed to create the events you type. See the Privacy Policy.
